# 정보보안기사 필기 학습 플랫폼

상명대 6인 캡스톤 프로젝트의 첫 배포용 공용 소스입니다.

## 현재 동작

- `/`: 서비스 이름과 **학습 시작** 링크
- `/learn`: 샘플 단원 **보안의 3요소**의 요약과 예시
- 휴대폰 화면에 맞춰 카드가 한 열로 배치됩니다.
- 로그인, DB, 문제풀이, AI 연결은 아직 구현하지 않았습니다.
- 학습 기록을 저장하지 않으며 외부 API를 호출하지 않습니다.

## 개발

Node.js 24.x, npm, Git을 사용합니다. 설치 버전은 `package-lock.json`으로 통일합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

```sh
npm run build
npm start
```

빌드와 실제 운영 실행 확인에 사용하는 명령입니다.
Windows PowerShell에서 npm 실행 정책 오류가 나면 `npm.cmd`를 사용합니다.

## 공용 파일

| 경로 | 내용 |
| --- | --- |
| `src/app/page.tsx` | 첫 화면 |
| `src/app/learn/page.tsx` | 개념학습 화면 |
| `src/content/concepts.ts` | 팀이 작성한 샘플 단원 데이터 |
| `src/app/layout.tsx` | 공통 헤더, 푸터, 문서 정보 |
| `src/app/globals.css` | 공통 스타일과 모바일 배치 |

가입·로그인과 게시판은 안재우 담당으로 첫 배포 확인 이후 연결합니다.
공통 환경·배포·콘텐츠·개념학습은 팀장 정재호가 관리합니다.
추가 프로젝트나 별도 저장소를 만들지 않고 이 소스를 함께 사용합니다.

## 첫 배포 완료 기준

다른 팀원이 자신의 휴대폰에서 공개 배포 주소를 열고 **학습 시작**을 눌러
**보안의 3요소** 화면을 확인합니다. `/learn`에서 새로고침해도 화면이 열려야 합니다.

저장소와 배포 주소는 실제 생성·검증한 뒤 기록합니다.
비밀번호, 인증 코드, API 키, `.env` 파일은 Git에 올리지 않습니다.

## jaeho 필수 기능 UI (2026-11-09)

이 절이 위의 첫 배포 상태 설명을 대체합니다. `/`는 학습 대시보드, `/learn`은 단원별 개념학습으로 시작합니다.

- 확정 목차: 7 PART / 42 SECTION. 명칭 수정은 `src/content/curriculum.ts`에서 합니다.
- 필수 메뉴: 대시보드, 개념학습, 문제풀이, 복습·분석, AI 학습, 도전장, 게시판, 회원.
- SECTION 01 개념요약과 직접 작성한 3문항만 제공하며 나머지 콘텐츠는 준비 중으로 표시합니다.
- 답안과 확신도를 모두 선택해야 제출할 수 있습니다. 제출 후 수정은 막고 해설을 표시합니다.
- 첫 제출 기준 정답률, 오답·불확실 답안 복습, 최근 제출 기록, 학습 완료 표시를 제공합니다.
- 닉네임, 게시글·댓글, 도전장 상태, 학습 기록은 localStorage의 `smu-ui-v1`에 저장합니다. 다른 브라우저·기기·계정과 공유되지 않습니다.
- 회원은 닉네임 프로필 체험입니다. 실제 회원가입·로그인·서버 채점·DB·AI·상대 전송은 미연결입니다. AI 설명은 고정 샘플입니다.

### 후속 연결 위치

`src/components/StudyApp.tsx`의 Data 타입, 초기 로딩/저장 effect, submit 함수 및 각 폼 처리 함수를 인증된 API로 교체합니다. 정답 판정과 정답 데이터는 운영 서비스에서 서버로 이동해야 합니다. 회원 식별은 닉네임 대신 서버 사용자 ID를 사용합니다. 도전장 수락은 현재 상태 변경 체험이며 실제 비동기 대결 결과 처리는 서버 담당입니다.

### 확인 순서

1. 닉네임 저장 → 대시보드 이름 확인.
2. 개념학습에서 목차 검색·PART 필터 → SECTION 01 완료 표시.
3. 문제 선택 + 확신도 → 제출 → 정오답과 해설 확인.
4. 복습·분석에서 첫 풀이 정답률과 복습 문제 확인 → 다시 풀기.
5. 새로고침 후 기록 유지 확인.
6. AI 고정 설명 → 보완문제, 도전장 생성 → 수락 체험, 게시글 → 댓글 등록.
7. 모바일 너비에서 메뉴 가로 이동 및 문제 선택·제출 확인.

검증: `npm run typecheck`, `npm run build`. 브라우저 상호작용 검증은 별도 필요합니다.
