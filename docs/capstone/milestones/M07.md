- 목표 날짜: 팀에서 입력
- 선행: [M03](M03.md), [M04](M04.md), [M05](M05.md), [M06](M06.md)

## 해야 할 일

- [ ] FR-SYS-01 [화면 이동과 주소 상태 복원](../requirements/sys/FR-SYS-01.md) — 정재호 및 전원 · `화면 완료` · A 1/2
- [ ] M07-01 비기능 요구사항별 측정 환경과 결과를 기록한다. A·B 등급은 필수, C 등급은 여유 시.
- [ ] M07-02 AT-01~20의 A 단계를 모두 합격시키고, B 단계 결과를 기록한다. 실패 항목은 수정·재시험한다.
- [ ] M07-03 공용 배포의 시연 동선·버전·실행 방법을 확인한다.

## 필요한 파일

[AI 읽기 규칙](../AI-작업안내.md)는 처음 한 번만 읽는다. 위에서 맡은 작업 하나의 상세 파일을 열고, 그 파일이 연결하는 규칙·데이터·시험만 추가로 확인한다.

## 완료 조건

공용 배포에서 전체 흐름이 두 계정으로 연결되고 기능별 수용 기준·관련 비기능 기준·AT-01~20 결과가 기록된다. 미검증 필수 항목이 남으면 완료 처리하지 않는다.

비기능 측정 결과는 [품질 검증 기록](../working/quality-results.md)에 남긴다.

기능 완료 체크는 해당 기능의 A 기준과 연결 시험의 A 단계를 기준으로 한다. B·C 미충족은 기능 파일의 판정 열에 남긴다.
