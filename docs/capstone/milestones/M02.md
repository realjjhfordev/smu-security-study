## 필요한 파일

[AI 읽기 규칙](../AI-작업안내.md)는 처음 한 번만 읽는다. 위에서 맡은 작업 하나의 상세 파일을 열고, 그 파일이 연결하는 규칙·데이터·시험만 추가로 확인한다.

## 완료 조건

개념 → 관련 문제 → 선택·확신도 → 서버 채점·저장 → 해설 흐름이 연결된다. 계정에 저장된 제출이 다른 기기에서도 확인되고 중복 요청이 기록을 늘리지 않는다.

기능 완료 체크는 해당 기능의 A 기준과 연결 시험의 A 단계를 기준으로 한다. B·C 미충족은 기능 파일의 판정 열에 남긴다.
