# AT-18 화면 이동·주소 복원·모바일

- 실행 상태: 미실시
- 단계 구성: A 4단계 · B 3단계 · C 2단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 대부분 예(A 1~4단계, B 5~7단계는 현재 배포에서 가능)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-SYS-01 화면 이동과 주소 상태 복원](../requirements/sys/FR-SYS-01.md)

## 준비

- PC Chrome, 팀원 휴대폰 1대(기종·브라우저 버전을 기록)
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.
