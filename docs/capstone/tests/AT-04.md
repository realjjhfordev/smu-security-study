# AT-04 학습 완료 표시와 기기 간 유지

- 실행 상태: 미실시
- 단계 구성: A 5단계 · B 2단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(서버 저장 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-LRN-04 학습 완료 표시](../requirements/lrn/FR-LRN-04.md)
- [FR-REV-03 학습 대시보드](../requirements/rev/FR-REV-03.md)

## 준비

- 계정 A(완료 단원 0개), 계정 B
- 브라우저1(PC), 브라우저2(휴대폰 또는 다른 브라우저)
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | A · 브라우저1 | SECTION 01에서 '학습 완료 표시' | 버튼이 '학습 완료 취소'로 바뀌고, 목록에 '완료', 대시보드 1 / 42 | |
| 2 | B | A · 브라우저1 | 같은 버튼을 빠르게 두 번 눌러 취소→완료 상태로 끝낸다 | 대시보드 1 / 42. DB에 A·SECTION 01 행이 1개 | |
| 3 | A | A · 브라우저1 | SECTION 02 완료 → 대시보드 | 2 / 42 | |
| 4 | A | A · 브라우저1 | 로그아웃 후 다시 로그인 | 2 / 42 유지 | |
| 5 | B | A · 브라우저2 | A로 로그인 | 2 / 42, SECTION 01·02가 '완료' | |
| 6 | A | A · 브라우저2 | SECTION 02 '학습 완료 취소' → 브라우저1 새로고침 | 두 브라우저 모두 1 / 42 | |
| 7 | A | B · 브라우저2 | A 로그아웃 후 B로 로그인 | 0 / 42 | |

'판정' 칸에는 합격·불합격·미실시 중 하나를 적는다. 불합격이면 실제로 본 결과를 아래 실행 기록에 적는다.

재시험은 이전 행을 지우지 않고 새 행을 추가한다. 상단 실행 상태도 마지막 결과에 맞춰 갱신한다. 비밀번호·토큰·개인정보를 증거에 넣지 않는다. 시험용 계정과 데이터는 운영 데이터와 구분한다.
