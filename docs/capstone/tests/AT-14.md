# AT-14 도전장 최종 제출과 공개 시점

- 실행 상태: 미실시
- 단계 구성: A 3단계 · B 3단계 · C 1단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(도전장 구현 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-CHL-03 도전장 답안 최종 제출](../requirements/chl/FR-CHL-03.md)

## 준비

- AT-13 도전장: A 제출 완료, B 참가했지만 미제출
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | B · 브라우저2 | 도전장 화면 확인 | A의 점수, 정답·해설이 보이지 않는다 | |
| 2 | B | A · 브라우저1 | A의 도전장 결과 화면과 Network 응답 확인 | '상대 제출 대기'. 정답·해설·B 점수가 화면과 응답에 없다 | |
| 3 | A | B · 브라우저2 | 4문항만 답하고 최종 제출 | 제출되지 않고 남은 문항 안내 | |
| 4 | A | B · 브라우저2 | 5문항 모두 답하고 최종 제출 | 결과가 공개된다. 이후 답을 바꿀 수 없다 | |
| 5 | B | B · 브라우저2 | 최종 제출 요청을 재전송 | 점수가 바뀌지 않고 제출은 1회 | |
| 6 | B | C · 브라우저3 | B의 제출 요청을 복사해 C 세션으로 실행 | 거부 | |
| 7 | C | B · 브라우저2 | (새 도전장에서) 2문항만 답한 뒤 새로고침 | 입력한 답이 유지된다(D05) | |

'판정' 칸에는 합격·불합격·미실시 중 하나를 적는다. 불합격이면 실제로 본 결과를 아래 실행 기록에 적는다.
