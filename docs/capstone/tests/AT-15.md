# AT-15 도전장 결과와 내 목록

- 실행 상태: 미실시
- 단계 구성: A 5단계 · B 1단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(도전장 구현 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-CHL-04 도전장 결과와 내 목록](../requirements/chl/FR-CHL-04.md)

## 준비

- 계정 A·B·C
- 도전장 문항의 정답은 팀 내부 정답표(문제 데이터)에서 확인해 맞힐 개수를 조절한다
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | A·B | 도전장 1: A는 3개, B는 2개 맞혀 제출 | A 화면 60 대 40 승리, B 화면 40 대 60 패배 | |
| 2 | A | A·B | 도전장 2: 둘 다 3개씩 맞혀 제출 | 두 화면 모두 60 대 60 무승부 | |
| 3 | A | A·B | 두 브라우저 새로고침 | 같은 결과가 유지된다 | |
| 4 | A | A · 브라우저1 | 내 도전장 목록 확인(새 도전장 3을 만들고 미제출 상태로 둔다) | 도전장 1·2는 '결과 완료', 도전장 3은 '제출 대기' | |
| 5 | A | A · 브라우저1 | 도전장 1 열기 | 5문항 정답·해설을 볼 수 있다 | |
| 6 | B | C · 브라우저3 | 도전장 1의 결과 주소를 직접 열기 | 거부 | |

'판정' 칸에는 합격·불합격·미실시 중 하나를 적는다. 불합격이면 실제로 본 결과를 아래 실행 기록에 적는다.
