# AT-02 로그인 상태와 접근 권한

- 실행 상태: 미실시
- 단계 구성: A 6단계 · B 2단계 · C 1단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(인증·서버 저장 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-AUTH-02 로그인](../requirements/auth/FR-AUTH-02.md)
- [FR-AUTH-03 로그아웃](../requirements/auth/FR-AUTH-03.md)
- [FR-AUTH-04 접근 권한과 로그인 상태 확인](../requirements/auth/FR-AUTH-04.md)

## 준비

- 계정 A·B(AT-01로 생성)
- A는 Q001, B는 Q003을 한 번씩 제출해 둔다
- 브라우저1에 A, 브라우저2에 B 로그인
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | A · 브라우저1 | 복습·분석의 최근 제출 기록 확인 | Q001만 보이고 Q003은 없다 | |
| 2 | A | B · 브라우저2 | 복습·분석의 최근 제출 기록 확인 | Q003만 보이고 Q001은 없다 | |
| 3 | A | A · 브라우저1 | 로그아웃 후 새로고침 | 로그인 안내가 나오고 개인 기록이 보이지 않는다 | |
| 4 | A | 비회원 · 브라우저1 | 문제풀이에서 Q001에 답과 확신도를 고르고 제출 | 로그인 안내. 기록이 생기지 않는다 | |
| 5 | A | A · 브라우저1 | 다시 로그인 | Q001 기록이 다시 보인다 | |
| 6 | B | A · 브라우저1 | 로그아웃 후 뒤로 가기, 그리고 복습 화면 주소를 직접 입력 | 어느 경우에도 개인 기록이 보이지 않는다 | |
| 7 | A | A · 브라우저1 | Network에서 기록 조회 요청을 복사(Copy as fetch)해 사용자 ID 또는 기록 ID를 B의 값으로 바꿔 콘솔에서 실행 | 거부(401·403 또는 빈 결과). 응답에 B의 기록 내용이 없다 | |
| 8 | B | 비회원 · 브라우저1 | 로그인 주소 뒤에 외부 복귀 주소(예: `?next=https://example.com`)를 붙여 로그인 | 외부 사이트로 이동하지 않고 학습 홈으로 간다 | |
| 9 | C | A · 브라우저1 | 저장소의 로그인 세션을 지우거나 만료시킨 뒤 복습 화면 새로고침 → 로그인 | 로그인 후 복습 화면으로 돌아온다 | |

'판정' 칸에는 합격·불합격·미실시 중 하나를 적는다. 불합격이면 실제로 본 결과를 아래 실행 기록에 적는다.
