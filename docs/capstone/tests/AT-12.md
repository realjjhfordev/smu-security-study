# AT-12 AI 요청 상태와 한도

- 실행 상태: 미실시
- 단계 구성: A 3단계 · B 2단계 · C 2단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(AI 연동 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-AI-03 AI 요청 상태와 한도 관리](../requirements/ai/FR-AI-03.md)

## 준비

- 계정 A
- 시험용으로 하루 한도를 2회로 낮출 수 있는 개발 환경(B 단계)
- 지연·오류를 흉내 낼 개발 환경(A·C 단계)
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | A · 브라우저1 | '추가 해설' 클릭 | 생성 중 표시가 나오고 버튼이 비활성이 된다 | |
| 2 | A | 비회원 · 브라우저1 | 배포 사이트 Sources 전체 검색으로 AI 키 앞부분과 키 변수 이름 검색 | 찾을 수 없다 | |
| 3 | A | A · 개발 환경 | AI가 오류를 돌려주게 한 뒤 요청 → 정상으로 되돌리고 '재시도' | 실패 안내와 재시도 버튼 → 재시도 성공 | |
| 4 | B | A · 브라우저1 | 생성 중에 버튼을 5번 누르고, 다른 탭에서도 같은 요청 | 공급자 사용량(또는 서버 로그)이 1만 늘어난다 | |
| 5 | B | A · 개발 환경 | 하루 한도 2회 설정 후 3번째 생성 요청 | 한도 안내. 외부 호출이 0회 | |
| 6 | C | A · 개발 환경 | 응답을 45초 넘게 지연 | 시간 초과 안내. 자동으로 계속 재시도하지 않는다 | |
| 7 | C | A · 개발 환경 | 서비스 전체 한도 도달, 한도 조회 실패를 각각 흉내 | 두 경우 모두 생성이 막힌다 | |
