# AT-10 AI 추가 해설 생성과 재조회

- 실행 상태: 미실시
- 단계 구성: A 2단계 · B 2단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(AI 연동 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-AI-01 선택 답안에 대한 AI 추가 해설](../requirements/ai/FR-AI-01.md)
- [FR-AI-03 AI 요청 상태와 한도 관리](../requirements/ai/FR-AI-03.md)

## 준비

- 계정 A(브라우저1), B(브라우저2)
- A가 Q003에 1번으로 오답 제출한 상태(AT-06)
- 배포 환경에 AI 키 설정, 공급자 대시보드에서 사용량 확인 가능
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.
