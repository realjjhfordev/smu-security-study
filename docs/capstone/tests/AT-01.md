# AT-01 회원가입과 로그인

- 실행 상태: 미실시
- 단계 구성: A 5단계 · B 2단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(인증 연동 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-AUTH-01 이메일 회원가입](../requirements/auth/FR-AUTH-01.md)
- [FR-AUTH-02 로그인](../requirements/auth/FR-AUTH-02.md)

## 준비

- 가입에 쓴 적 없는 이메일 2개(팀원 메일 또는 시험용 메일)
- 브라우저1(PC Chrome)
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | 비회원 · 브라우저1 | /signup에서 닉네임 `시험A`, 새 이메일, 8자 이상 비밀번호를 두 칸에 같게 입력하고 가입 | 가입 완료 또는 이메일 확인 안내가 나온다. 인증 서비스 사용자 목록에 계정이 1개 생긴다 | |
| 2 | A | 비회원 · 브라우저1 | 1단계와 같은 이메일로 다시 가입 | 중복 이메일 안내. 사용자 수가 늘지 않는다 | |
| 3 | A | 비회원 · 브라우저1 | 두 번째 새 이메일로, 비밀번호 확인 칸만 다르게 입력하고 가입 | 불일치 안내. 계정이 생기지 않는다 | |
| 4 | B | 1단계 계정 · 브라우저1 | (D01에서 이메일 확인을 쓰기로 한 경우) 확인 메일을 누르기 전에 로그인해 문제를 제출 | 확인 필요 안내가 나오고 제출이 막힌다 | |
| 5 | A | 1단계 계정 · 브라우저1 | (이메일 확인 후) /login에서 로그인 | 대시보드에 `시험A`님이 표시된다 | |
| 6 | A | 비회원 · 브라우저1 | 1단계 이메일 + 틀린 비밀번호로 로그인 | 로그인 실패 안내. 이메일과 비밀번호 중 무엇이 틀렸는지 구분해 알려주지 않는다 | |
| 7 | B | 비회원 · 브라우저1 | 개발자 도구 Network를 Offline으로 바꾼 뒤 새 이메일로 가입 | 실패와 재시도 안내. 가입 성공으로 표시되지 않는다 | |

'판정' 칸에는 합격·불합격·미실시 중 하나를 적는다. 불합격이면 실제로 본 결과를 아래 실행 기록에 적는다.
