## 공통 준비

| 항목 | 내용 |
| --- | --- |
| 계정 A·B | 시연용 계정 2개. 이메일·비밀번호는 팀 내부에만 기록하고 시험 파일에는 'A', 'B'로만 적는다 |
| 계정 C·D | C는 도전장 제3자·권한 시험용, D는 기록이 없어야 하는 AT-09용. 시험마다 새로 만들어도 된다 |
| 브라우저1 | PC Chrome. 주로 계정 A |
| 브라우저2 | 휴대폰 또는 PC의 다른 브라우저. 주로 계정 B. 같은 브라우저의 다른 탭은 로그인 상태가 섞이므로 쓰지 않는다 |
| 브라우저3 | 시크릿 창. 비회원 또는 계정 C |
| 정답표 | 문항별 정답은 문제 데이터(서버 전환 후에는 DB)에서 확인한다. 시험 파일에 적힌 정답은 2026-11-16 데이터 기준 |
| 개발 환경 | 'A · 개발 환경'처럼 적힌 단계는 오류·지연·한도를 흉내 낼 수 있는 로컬 또는 미리보기 배포에서 수행한다 |

## 개발자 도구로 요청을 조작하는 방법

권한 시험(B 단계)에서 자주 쓴다.

1. F12 → Network 탭을 연 상태에서 해당 동작을 한 번 정상 수행한다.
2. 생긴 요청을 오른쪽 클릭 → Copy → Copy as fetch.
3. Console에 붙여 넣고 바꿀 값(사용자 ID, 글 ID, 답 번호 등)만 고쳐 실행한다.
4. 응답 상태 코드와 내용, 그리고 화면·DB에 변화가 없는지 확인한다.

'Offline'은 Network 탭의 'No throttling' 목록에서 고른다. 'Replay XHR'는 요청 오른쪽 클릭 메뉴에 있다.

통합시험과 별도로 각 기능의 수용 기준 및 [비기능 요구사항](../common/quality.md)을 검증한다.
