# AT-03 개념학습 탐색·검색·문제 연결

- 실행 상태: 미실시
- 단계 구성: A 7단계 · B 4단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 예(현재 배포에서 실행 가능)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.
