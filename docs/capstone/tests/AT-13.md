# AT-13 도전장 생성과 초대 참가

- 실행 상태: 미실시
- 단계 구성: A 4단계 · B 3단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(도전장 구현 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-CHL-01 도전장 생성](../requirements/chl/FR-CHL-01.md)
- [FR-CHL-02 초대 링크와 참가](../requirements/chl/FR-CHL-02.md)

## 준비

- 계정 A(브라우저1), B(브라우저2), C(브라우저3: 시크릿 창)
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | A · 브라우저1 | 도전장 만들기 | 서로 다른 5문항이 고정 순서로 나오고 풀이 화면이 열린다. 초대 링크 복사는 아직 비활성. 5문항 번호를 실행 기록에 적는다 | |
| 2 | A | A · 브라우저1 | 5문항을 풀고 최종 제출 | 제출 완료. 초대 링크 복사가 활성화된다 | |
| 3 | A | A · 브라우저1 | 복사한 링크를 A 브라우저에서 열기 | 본인 도전장에는 참가할 수 없다는 안내 | |
| 4 | A | B · 브라우저2 | 링크를 열어 참가 | A가 기록한 5문항과 같은 번호·순서 | |
| 5 | B | C · 브라우저3 | C로 로그인해 같은 링크 열기 | 이미 참가자가 있다는 안내 | |
| 6 | B | 비회원 · 브라우저3 | 로그아웃 상태에서 새 도전장 링크를 열고 로그인 | 로그인 후 같은 초대 화면으로 돌아온다 | |
| 7 | B | A · 브라우저1 | '도전장 만들기' 요청을 Network에서 재전송 | 도전장이 하나만 생긴다 | |

'판정' 칸에는 합격·불합격·미실시 중 하나를 적는다. 불합격이면 실제로 본 결과를 아래 실행 기록에 적는다.
