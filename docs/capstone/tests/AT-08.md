# AT-08 복습 목록 갱신

- 실행 상태: 미실시
- 단계 구성: A 6단계 · B 2단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(서버 저장 후). 1~5단계는 지금 브라우저 저장으로 미리 확인 가능
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-REV-01 개인 풀이 기록과 복습 목록](../requirements/rev/FR-REV-01.md)
- [FR-REV-03 학습 대시보드](../requirements/rev/FR-REV-03.md)

## 준비

- 계정 A(Q015를 푼 적 없음), 계정 B
- Q015 정답은 2번(2026-11-17, 527문항 기준)
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.
