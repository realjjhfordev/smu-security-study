## 준비

- 기존 작업 폴더와 별도로 저장소를 복제하고, 시험할 커밋을 선택한다. 복제 폴더에서 `git status --short` 출력이 비어 있는지 확인한 뒤 진행한다.
- 2~5단계는 한 번에 하나씩 실행한다. 각 단계 후 `git diff`로 시험 변경만 있는지 확인하고 복제 폴더에서 해당 파일만 복원한다. 2~4단계는 `git restore -- src/content/questions.ts`, 5단계는 `git restore -- src/content/lessons/section-09.ts`를 실행한다.
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.
