# AT-06 문제 제출과 서버 채점

- 실행 상태: 미실시
- 단계 구성: A 8단계 · B 3단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(서버 채점 후). 1·2·11단계는 지금도 가능
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 준비

- 계정 A 로그인, 브라우저1(PC Chrome, 개발자 도구 열기)
- 정답표: Q001=4, Q003=2, Q004=4, Q007=4, Q010=3
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.
