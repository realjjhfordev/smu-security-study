# AT-20 최종 시연(두 계정 전체 흐름)

- 실행 상태: 미실시
- 단계 구성: A 13단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(전체 구현 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- 전체 기능의 최종 통합 시험

## 준비

- 배포 주소와 시험한 커밋을 기록
- 계정 A: PC Chrome, 계정 B: 휴대폰
- 계정 A는 다른 시험에 쓰지 않은 시연 전용 계정으로 하고, AT-09 세트1을 미리 처음 풀어 둔다(Q007·Q010만 정답). 개념별 40%·취약을 보여주기 위해서다
- 시연 5분 전에 배포 주소를 한 번 열어 무료 서버를 깨워 두고, AI 남은 한도를 확인한다
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.
