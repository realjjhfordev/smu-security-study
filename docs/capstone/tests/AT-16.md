# AT-16 게시글·댓글 공유와 작성자 권한

- 실행 상태: 미실시
- 단계 구성: A 7단계 · B 3단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(게시판 서버 저장 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-COM-01 게시글 목록과 상세 조회](../requirements/com/FR-COM-01.md)
- [FR-COM-02 게시글 작성](../requirements/com/FR-COM-02.md)
- [FR-COM-03 게시글 수정과 삭제](../requirements/com/FR-COM-03.md)
- [FR-COM-04 댓글 작성과 조회](../requirements/com/FR-COM-04.md)

## 준비

- 계정 A(브라우저1), B(브라우저2)
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | A · 브라우저1 | 게시판 → 제목 `AT16 시험 글`, 본문 두 줄 작성 | 상세 화면으로 이동. 작성자 A 닉네임과 작성 시각이 보인다 | |
| 2 | A | B · 브라우저2 | 새로고침 → 목록 → 글 열기 | 목록에 제목·작성자·시각·댓글 0, 상세에 두 줄 본문이 그대로 | |
| 3 | A | B · 브라우저2 | 댓글 `B 댓글` 작성 | 댓글 1개, 작성자 B | |
| 4 | A | A · 브라우저1 | 글 새로고침 | B 댓글이 보이고 댓글 수 1 | |
| 5 | A | A·B | 두 화면의 버튼 비교 | A 화면에만 수정·삭제 버튼이 있다 | |
| 6 | A | A · 브라우저1 | 제목을 `AT16 수정됨`으로 수정 → B 새로고침 | B 화면에도 수정된 제목 | |
| 7 | B | B · 브라우저2 | A의 수정 요청을 복사해 B 세션으로 실행 | 거부. 글 내용 그대로 | |
| 8 | B | A · 브라우저1 | 삭제 → 확인 창에서 취소 | 글이 그대로 있다 | |
| 9 | A | A · 브라우저1 | 삭제 → 확인 | 목록으로 이동, 글이 사라진다. B가 상세 주소를 새로고침하면 '찾을 수 없음' | |
| 10 | B | B · 브라우저2 | 없는 글 ID 주소 열기 | '찾을 수 없음' 안내, 화면 오류 없음 | |

'판정' 칸에는 합격·불합격·미실시 중 하나를 적는다. 불합격이면 실제로 본 결과를 아래 실행 기록에 적는다.
