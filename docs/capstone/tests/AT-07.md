# AT-07 중복 제출과 실패 처리

- 실행 상태: 미실시
- 단계 구성: B 3단계 · C 2단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(서버 채점 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-QST-03 서버 채점과 답안 저장](../requirements/qst/FR-QST-03.md)

## 준비

- 계정 A 로그인, 브라우저1(개발자 도구)
- C 단계는 서버 쪽 지연·오류를 흉내 낼 수 있는 개발 환경 필요
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.
