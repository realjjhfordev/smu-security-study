# AT-17 게시판 입력 검증

- 실행 상태: 미실시
- 단계 구성: A 1단계 · B 5단계 · C 1단계 ([등급 정의](../common/scope.md))
- 지금 실행 가능: 아니오(게시판 서버 저장 후)
- 합격 기준: A 단계가 모두 '합격'이면 이 시험은 합격이다. B·C 단계 결과는 따로 기록한다.

## 관련 기능

- [FR-COM-02 게시글 작성](../requirements/com/FR-COM-02.md)
- [FR-COM-03 게시글 수정과 삭제](../requirements/com/FR-COM-03.md)
- [FR-COM-04 댓글 작성과 조회](../requirements/com/FR-COM-04.md)

## 준비

- 계정 A, 시험용 글 1개
- 공통 준비(계정·브라우저·개발자 도구 사용법)는 [시험 색인](INDEX.md)을 따른다.

## 절차

| # | 등급 | 누가 · 어디서 | 조작 | 기대 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| 1 | A | A · 브라우저1 | 제목에 공백 3칸만 입력하고 등록 | 저장되지 않고 안내가 나온다 | |
| 2 | B | A · 브라우저1 | 작성 요청을 복사해 제목 101자, 본문 3001자로 바꿔 각각 실행 | 서버가 거부한다 | |
| 3 | B | A · 브라우저1 | 본문에 `<script>alert(1)</script>`와 `<img src=x onerror=alert(1)>`를 넣어 등록 | 알림 창이 뜨지 않고 글자 그대로 보인다 | |
| 4 | B | A · 브라우저1 | 빈 댓글 요청 실행 | 거부 | |
| 5 | B | 비회원 · 브라우저3 | 댓글 작성 요청 실행 | 거부 | |
| 6 | B | A · 브라우저1 | 삭제한 글 ID로 댓글 요청 실행 | 거부 | |
| 7 | C | A · 브라우저1 | 등록 버튼을 빠르게 3번 클릭 | 글 1개 | |

'판정' 칸에는 합격·불합격·미실시 중 하나를 적는다. 불합격이면 실제로 본 결과를 아래 실행 기록에 적는다.
