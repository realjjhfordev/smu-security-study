# FR-QST-02 공통 문제 화면과 답안 선택

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 윤도경
- 작업 체크: [M02](../../milestones/M02.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료·정답 노출**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-QST-03](FR-QST-03.md), [FR-AI-02](../ai/FR-AI-02.md), [NFR-SEC-02](../../common/quality.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

기출 또는 본인 AI 문제에 대한 풀이 접근 권한이 있다.

## 입력

문제 ID, 선택한 보기 1~4, 확신도 1개. 화면 확신도는 확실해요·헷갈려요·모르겠어요다.

## 처리 흐름

1. 문제와 보기 4개를 표시한다.
2. 단일 보기와 확신도를 선택한다.
3. 두 값이 모두 있어야 제출할 수 있다.
4. 제출 중 선택 변경과 중복 버튼 동작을 막는다.

## 출력과 저장

기출과 AI 문제에서 같은 조작 방식을 제공한다. 제출 전 정답·해설은 화면뿐 아니라 클라이언트 전달 데이터에도 포함하지 않는다.

## 예외 처리

보기 또는 확신도 누락 시 제출을 막고 안내한다. 문제 이동 시 이전 문제의 미제출 답안을 새 문제에 적용하지 않는다.

## 현재 상태와 남은 일

보기 1개·확신도 필수 선택과 중복 제출 방지가 동작함. 단, 정답·해설이 questions.ts에 함께 있어 브라우저 번들로 전달됨.

- [ ] 공개 문제 데이터(본문·보기)와 정답·해설 분리
- [ ] AI 문제도 같은 카드 컴포넌트로 표시

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
