# FR-QST-01 문제 검색과 범위 선택

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 윤도경
- 작업 체크: [M02](../../milestones/M02.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-QST-02](FR-QST-02.md), [FR-SYS-02](../sys/FR-SYS-02.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

공개된 일반 기출문제가 등록되어 있다.

## 입력

PART, SECTION, 개념, Q번호 또는 검색어.

## 처리 흐름

1. 선택한 범위 안에서 Q번호·문제 본문·단원 이름으로 검색한다.
2. 결과 개수와 목록을 표시한다.
3. 선택한 문제를 공통 풀이 화면에 전달한다.
4. 이전·다음은 현재 결과 범위 안에서 이동한다.

## 출력과 저장

원래 Q번호를 유지한다. 번호가 연속적이지 않아도 정상 처리한다. AI 보완문제는 일반 기출 목록과 구분한다.

## 예외 처리

0건이면 조건 변경을 안내한다. 범위 밖의 현재 문제는 명확히 표시하고 범위 내 문제 선택을 제공한다. 없는 번호를 배열 순서로 대체하지 않는다.

## 현재 상태와 남은 일

527문항 검색·PART/단원 필터·결과 범위 안 이전/다음·PART 7 미등록 안내가 동작함.

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
