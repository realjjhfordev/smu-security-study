# FR-QST-04 정답 해설과 재풀이

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 윤도경
- 작업 체크: [M02](../../milestones/M02.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료·서버 미연결**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-QST-03](FR-QST-03.md), [FR-LRN-03](../lrn/FR-LRN-03.md), [FR-AI-01](../ai/FR-AI-01.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

일반 기출 또는 AI 문제의 제출 저장이 완료되었다.

## 입력

제출 ID와 다음 문제·같은 문제 다시 풀기·관련 개념·추가 해설 선택.

## 처리 흐름

1. 내 답·정답·정오답·해설을 표시한다.
2. 같은 문제 다시 풀기를 선택하면 입력을 초기화하고 새 풀이로 시작한다.
3. 다음 문제 또는 관련 개념으로 이동한다.

## 출력과 저장

재풀이는 새 기록을 만들되 일반 기출 첫 풀이 기록은 바꾸지 않는다. AI 해설은 별도 버튼 요청 시만 생성한다.

## 예외 처리

결과 조회 권한이 없으면 표시하지 않는다. 문제 내용이 수정된 경우 해당 제출 당시 버전의 결과를 구분한다. 마지막 문제에서 범위 밖 이동을 막는다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |

| A | 제출 후 내 답·정답·해설이 표시되고, 다시 풀기는 새 기록을 만들며 첫 풀이 정답률은 바뀌지 않는다. | 부분 |
| C | 문제 내용이 수정되면 제출 당시 버전의 결과를 구분해 보여준다(BR-08). | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

제출 후 내 답·정답·해설 표시, 같은 문제 다시 풀기가 동작함. 현재는 브라우저 데이터 기준.

- [ ] 서버 채점 결과로 해설 표시
- [ ] 재풀이를 새 제출 기록으로 서버 저장

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-06](../../tests/AT-06.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
