# FR-AI-02 같은 출제포인트의 보완문제 생성

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 정유민 및 윤도경
- 작업 체크: [M04](../../milestones/M04.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **미구현**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-QST-02](../qst/FR-QST-02.md), [FR-QST-03](../qst/FR-QST-03.md), [FR-AI-03](FR-AI-03.md), [DR-04](../../common/data.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

본인의 오답 기출 제출 및 해당 출제포인트가 존재한다.

## 입력

원본 문제 ID·제출 ID와 보완문제 생성 요청.

## 처리 흐름

1. 원본과 같은 출제포인트로 객관식 1문항을 서버에서 요청한다.
2. 문제·보기 4개·단일 정답·해설·개념 연결을 검증한다.
3. 새 AI 문제 ID로 저장한다.
4. 공통 풀이 화면으로 전달한다.

## 출력과 저장

원본과 연결된 개인 AI 문제를 제공한다. 정답·해설은 서버에 보관하고 답안 제출 후 공개한다. 일반 기출 Q번호를 재사용하지 않는다.

## 예외 처리

보기 부족·정답 범위 오류·빈 해설이면 저장하지 않고 재시도를 안내한다. 출제포인트 미등록이면 생성을 막고 준비 중을 안내한다.

## 현재 상태와 남은 일

보완문제 생성 기능 없음.

- [ ] 오답 결과 화면에 '보완문제 만들기' 버튼
- [ ] 보기 4개·정답 1개·해설 형식 검증 후 저장
- [ ] 공통 문제 화면으로 열어 서버 채점

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
