# FR-AI-03 AI 요청 상태와 한도 관리

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 정유민
- 작업 체크: [M04](../../milestones/M04.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **미구현**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-AI-01](FR-AI-01.md), [FR-AI-02](FR-AI-02.md), [NFR-OPS-01](../../common/quality.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

로그인 사용자가 AI 생성 또는 저장 결과 조회를 요청한다.

## 입력

요청 종류·요청 ID·원본 제출 ID. 계정별·서비스 전체 한도는 D04로 설정한다.

## 처리 흐름

1. 대기·생성 중·성공·실패 상태를 관리한다.
2. 생성 중 동일 요청을 중복 실행하지 않는다.
3. 성공 결과를 저장한다.
4. 실패하면 이유와 재시도 가능 여부를 표시한다.

## 출력과 저장

생성 중 안내, 저장된 결과 목록·재조회, 잔여 사용 가능 여부를 제공한다. API 키는 서버에서만 사용한다.

## 예외 처리

한도 도달 시 새 외부 호출을 막는다. 제한 확인이 실패하면 생성하지 않는다. 자동 무한 재시도나 유료 플랜 전환을 하지 않는다.

## 현재 상태와 남은 일

AI 요청 상태·한도 관리 없음.

- [ ] 생성 중·성공·실패 상태 표시
- [ ] D04 한도 적용
- [ ] API 키 서버 환경 변수로만 사용

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
