# FR-AI-01 선택 답안에 대한 AI 추가 해설

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 정유민
- 작업 체크: [M04](../../milestones/M04.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **목업**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-QST-03](../qst/FR-QST-03.md), [FR-AI-03](FR-AI-03.md), [DR-04](../../common/data.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

본인의 채점된 기출 제출 기록이 있다.

## 입력

제출 ID와 추가 해설 요청. 문제·선택 답·정답·기본 해설은 서버가 조회한다.

## 처리 흐름

1. 권한과 사용 한도를 확인한다.
2. 문제와 선택 답의 차이를 설명하도록 서버에서 AI를 호출한다.
3. 비어 있지 않은 설명인지 검증한다.
4. 사용자·제출에 연결해 저장한다.

## 출력과 저장

선택한 답이 맞거나 틀린 이유와 핵심 개념 설명 1건을 표시한다. AI 생성 표시와 저장된 결과 재조회 기능을 제공한다.

## 예외 처리

시간 초과·한도·잘못된 응답은 실패로 표시한다. 실패해도 원래 채점·기본 해설은 유지한다. 저장 결과를 다시 여는 동작은 AI를 재호출하지 않는다.

## 현재 상태와 남은 일

'AI 학습' 탭에 고정 문구 1개만 있음. 실제 모델 호출 없음.

- [ ] 무료 모델 선택과 서버 호출
- [ ] 제출 결과 화면에 '추가 해설' 버튼
- [ ] 결과 저장·재조회

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-10](../../tests/AT-10.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
