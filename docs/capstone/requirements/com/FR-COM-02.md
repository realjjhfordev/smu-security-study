# FR-COM-02 게시글 작성

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 안재우
- 작업 체크: [M06](../../milestones/M06.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **부분(브라우저 저장)**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-AUTH-04](../auth/FR-AUTH-04.md), [FR-COM-01](FR-COM-01.md), [NFR-SEC-01](../../common/quality.md)

## 시작 조건

로그인 사용자가 글 작성 화면에 접근한다.

## 입력

제목·본문. 공백만 있는 값은 허용하지 않으며 길이는 D03을 적용한다.

## 처리 흐름

1. 입력을 검사한다.
2. 서버에서 작성자를 로그인 사용자로 지정한다.
3. 글과 서버 작성 시각을 저장한다.
4. 저장된 상세 화면으로 이동한다.

## 출력과 저장

글 ID와 저장 성공 결과를 제공한다. HTML·스크립트 문자열은 실행하지 않고 텍스트로 표시한다.

## 예외 처리

저장 실패 시 입력을 유지하고 재시도를 제공한다. 동일 요청의 중복 제출은 글 1개로 처리한다. 임의 작성자 ID는 적용하지 않는다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 로그인 사용자가 쓴 글이 저장되어 다른 계정에서도 보이고, 빈 제목은 저장되지 않는다. | 부분 |
| B | 길이 초과는 거부하고, 스크립트 형태의 본문은 실행되지 않고 글자로 표시된다. 작성자는 서버가 정한다. | 부분 |
| C | 같은 요청을 중복 제출해도 글은 1개다. | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

제목·본문 입력과 길이 제한(100/3000자)이 있지만 브라우저에만 저장되고 작성자는 닉네임 문자열임.

- [ ] 로그인 사용자를 작성자로 서버 저장
- [ ] 서버 쪽 입력 검사

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
