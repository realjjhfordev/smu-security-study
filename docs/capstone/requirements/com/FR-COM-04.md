# FR-COM-04 댓글 작성과 조회

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 안재우
- 작업 체크: [M06](../../milestones/M06.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **부분(브라우저 저장)**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-COM-01](FR-COM-01.md), [FR-AUTH-04](../auth/FR-AUTH-04.md), [DR-06](../../common/data.md)

## 시작 조건

로그인 사용자와 삭제되지 않은 게시글이 존재한다.

## 입력

게시글 ID·댓글 본문. 공백만 있는 값·길이 초과는 D03으로 검사한다.

## 처리 흐름

1. 대상 글과 작성 권한을 확인한다.
2. 작성자·서버 시각과 함께 댓글을 저장한다.
3. 상세 화면과 댓글 수를 갱신한다.
4. 다른 사용자는 새로고침으로 댓글을 읽는다.

## 출력과 저장

댓글 내용·작성자·작성 시각을 표시한다. 댓글 수정·삭제는 이번 필수 범위에 포함하지 않는다.

## 예외 처리

삭제된 글에는 댓글을 추가하지 않는다. 통신 실패 시 입력을 유지한다. 반복 클릭으로 같은 요청의 댓글을 중복 저장하지 않는다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | B가 A의 글에 쓴 댓글을 A가 새로고침해 볼 수 있고, 댓글 수가 1 늘어난다. | 부분 |
| B | 빈 내용·비로그인·삭제된 글에 대한 댓글은 거부된다. | 부분 |
| C | 연타해도 같은 댓글이 중복 저장되지 않는다. | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

댓글 입력·표시가 있지만 브라우저에만 저장되고 작성자·시각이 없음.

- [ ] 댓글 서버 저장(작성자·시각)
- [ ] 삭제된 글·비로그인 댓글 거부

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
