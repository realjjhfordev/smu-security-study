# FR-COM-01 게시글 목록과 상세 조회

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 안재우
- 작업 체크: [M06](../../milestones/M06.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **부분(브라우저 저장)**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-COM-02](FR-COM-02.md), [FR-COM-04](FR-COM-04.md), [DR-06](../../common/data.md)

## 시작 조건

공유 게시판이 제공되고 읽기 권한 정책 D02를 적용한다.

## 입력

목록 페이지 또는 게시글 ID.

## 처리 흐름

1. 서버의 게시글을 최신순으로 조회한다.
2. 제목·작성자·작성 시각·댓글 수를 표시한다.
3. 글을 선택하면 본문과 댓글을 상세 화면에서 조회한다.

## 출력과 저장

같은 게시글이 다른 사용자 기기에서도 표시된다. 긴 목록은 D06의 페이지 단위로 제공한다.

## 예외 처리

글이 없으면 빈 목록 안내를 표시한다. 삭제된 ID는 찾을 수 없음으로 안내한다. 조회 실패를 빈 게시판으로 표시하지 않는다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | A가 쓴 글을 B가 목록과 상세 화면에서 볼 수 있다. | 미충족 |
| B | 잘못된 글 ID는 '찾을 수 없음'으로 안내하고, 조회 실패를 빈 게시판으로 표시하지 않는다. | 미충족 |
| C | 목록을 페이지 단위로 나눈다(D06). | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

한 화면에 글 목록을 펼쳐 보여줌. 상세 화면 없음, 브라우저에만 저장되어 다른 사용자에게 보이지 않음.

- [ ] 게시글 서버 저장·최신순 조회
- [ ] 목록과 상세 화면 분리

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-16](../../tests/AT-16.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
