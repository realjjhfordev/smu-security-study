# FR-CHL-02 초대 링크와 참가

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 이재윤
- 작업 체크: [M05](../../milestones/M05.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **미구현**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-AUTH-04](../auth/FR-AUTH-04.md), [FR-CHL-01](FR-CHL-01.md), [DR-05](../../common/data.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

생성자가 5문항 답안을 최종 제출했고 참가자는 아직 없다.

## 입력

초대 링크의 코드와 참가하려는 로그인 사용자.

## 처리 흐름

1. 코드를 검증한다.
2. 생성자와 다른 사용자인지 확인한다.
3. 빈 참가자 자리를 한 계정에만 배정한다.
4. 참가자에게 고정된 동일 5문항을 연다.

## 출력과 저장

초대 링크 복사 기능과 참가 상태를 제공한다. 비회원은 로그인 후 같은 초대 화면으로 돌아온다.

## 예외 처리

잘못된 코드·본인 참가·이미 찬 도전장은 거부한다. 두 계정이 동시에 참가 요청해도 한 계정만 참가자가 된다. 기존 참가자의 재접속은 허용한다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | A가 만든 링크로 B가 참가하고, B에게 A와 같은 5문항이 같은 순서로 열린다. | 미충족 |
| A | A는 자기 도전장에 참가자로 들어갈 수 없다. | 미충족 |
| B | 이미 B가 참가한 도전장에 C는 참가할 수 없고, 비회원은 로그인 후 같은 초대 화면으로 돌아온다. | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

초대 링크·참가 기능 없음.

- [ ] 초대 코드 생성과 링크 복사
- [ ] 참가자 1명 배정과 본인 참가 차단

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-13](../../tests/AT-13.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
