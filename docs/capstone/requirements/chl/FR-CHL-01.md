# FR-CHL-01 도전장 생성

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 이재윤
- 작업 체크: [M05](../../milestones/M05.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **목업**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-CHL-03](FR-CHL-03.md), [DR-05](../../common/data.md), [BR-04](../../common/rules.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

로그인 사용자와 시연용 기출 5문항이 준비되어 있다.

## 입력

도전장 생성 요청. 문제 묶음·문항 수는 서버가 지정한다.

## 처리 흐름

1. 서로 다른 기출 5개를 선택한다.
2. 생성 시점의 문제 버전·순서를 고정한다.
3. 생성자와 도전장 ID를 저장한다.
4. 생성자 풀이 화면을 연다.

## 출력과 저장

도전장 1개와 고정된 5문항 목록을 생성한다. 생성자 제출 완료 전에는 초대 링크 공유 단계를 활성화하지 않는다.

## 예외 처리

문항 부족·미등록·정답 누락이면 생성하지 않는다. 동일 생성 요청 재전송으로 중복 도전장을 만들지 않는다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 도전장을 만들면 서로 다른 5문항이 고정된 순서로 저장되고 생성자가 바로 풀 수 있다. | 미충족 |
| B | 생성 요청을 다시 보내도 도전장이 중복 생성되지 않는다. | 미충족 |
| C | 원본 문제를 수정해도 진행 중인 도전장의 문항·정답은 바뀌지 않는다(버전 고정). | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

상대 닉네임을 적으면 브라우저에 '샘플 도전장'만 저장됨. 문항 고정·서버 저장 없음.

- [ ] 서로 다른 기출 5문항 선택·순서 고정 저장
- [ ] 생성자 풀이 화면

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험
