# FR-CHL-03 도전장 답안 최종 제출

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 이재윤 및 윤도경
- 작업 체크: [M05](../../milestones/M05.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **미구현**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-QST-03](../qst/FR-QST-03.md), [FR-CHL-02](FR-CHL-02.md), [FR-CHL-04](FR-CHL-04.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

로그인한 생성자 또는 참가자가 자신의 도전장을 푼다.

## 입력

도전장 ID, 고정된 5문항의 답·확신도, 중복 방지 요청 ID.

## 처리 흐름

1. 모든 필수 답안을 검사한다.
2. 참가 권한과 미제출 상태를 확인한다.
3. 서버에서 5문항을 채점한다.
4. 답안·점수·제출 시각을 일괄 저장하고 수정 불가 상태로 전환한다.

## 출력과 저장

본인 제출 완료를 표시한다. 양쪽 최종 제출 전에는 정답·해설·상대 점수를 공개하지 않는다. 초대 공유는 생성자 제출 후 허용한다.

## 예외 처리

미완성 답안은 최종 제출할 수 없다. 중복 제출은 기존 결과만 반환한다. 일부 문항만 저장된 상태로 완료 처리하지 않는다. 입력 임시 보존은 D05를 따른다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 5문항 답을 한 번에 제출하면 서버가 채점해 저장하고, 이후 수정할 수 없다. | 미충족 |
| A | 상대가 제출하기 전에는 상대 점수가 보이지 않는다. | 미충족 |
| B | 먼저 제출한 계정도 상대 제출 전에는 정답·해설을 볼 수 없다. 중복 제출은 점수를 바꾸지 않고, 미참가자 제출은 거부된다. | 미충족 |
| C | 최종 제출 전 입력을 서버에 임시 저장한다(D05). | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

도전장 답안 제출 기능 없음.

- [ ] 5문항 일괄 제출과 서버 채점
- [ ] 제출 후 수정 불가 처리
- [ ] 공개 시점 제한

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-14](../../tests/AT-14.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
