# FR-CHL-04 도전장 결과와 내 목록

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 이재윤
- 작업 체크: [M05](../../milestones/M05.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **미구현**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-CHL-03](FR-CHL-03.md), [BR-04](../../common/rules.md), [DR-05](../../common/data.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

본인이 생성자 또는 참가자인 도전장이 있다.

## 입력

내 목록 조회 또는 도전장 ID.

## 처리 흐름

1. 본인이 관련된 도전장만 조회한다.
2. 참가 대기·제출 대기·결과 완료를 구분한다.
3. 양쪽 제출이 끝나면 점수와 승패를 계산한다.
4. 새로고침으로 상태를 갱신한다.

## 출력과 저장

각자 정답 수 0~5와 점수 0~100, 승리·패배·무승부를 표시한다. 완료 후 정답·해설 조회를 제공한다.

## 예외 처리

상대 미제출은 결과 대기로 표시한다. 접속 순서·제출 속도로 승패를 정하지 않는다. 타인의 도전장 목록과 결과 접근을 거부한다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | A 3개·B 2개 정답이면 60 대 40으로 A 승리, 3개씩이면 무승부가 두 계정에서 똑같이 보인다. | 미충족 |
| A | 내 도전장 목록에서 참가 대기·제출 대기·결과 완료를 구분하고 결과를 다시 볼 수 있다. | 미충족 |
| B | 다른 사람의 도전장 목록과 결과에는 접근할 수 없다. | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

결과·승패·내 목록 기능 없음.

- [ ] 양쪽 제출 후 점수·승패 계산
- [ ] 내 도전장 목록과 상태 구분

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-15](../../tests/AT-15.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
