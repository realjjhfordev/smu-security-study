# FR-AUTH-04 접근 권한과 로그인 상태 확인

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 안재우
- 작업 체크: [M01](../../milestones/M01.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **미구현**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-AUTH-02](FR-AUTH-02.md), [DR-01](../../common/data.md), [NFR-SEC-01](../../common/quality.md)

## 시작 조건

개인 기록 또는 저장·생성 기능을 요청한다.

## 입력

로그인 상태와 요청 대상 식별자. 클라이언트가 보낸 사용자 ID만으로 소유권을 판단하지 않는다.

## 처리 흐름

1. 서버가 로그인 상태를 검증한다.
2. 개인 데이터의 소유자 또는 도전장 참가자 여부를 검사한다.
3. 허용된 요청만 처리한다.
4. 만료 시 로그인 후 원래 내부 화면으로 돌아가도록 안내한다.

## 출력과 저장

비회원은 공개 개념을 조회할 수 있다. 개인 풀이·AI·도전장·게시판 쓰기는 로그인 후 제공한다. 게시판 읽기는 D02를 따른다.

## 예외 처리

미로그인·만료는 로그인 안내, 다른 사람 소유의 데이터는 접근 거부로 처리한다. 실패 응답에 타인의 내용을 포함하지 않는다.

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

모든 기록이 브라우저 localStorage에 있어 계정·권한 개념이 없음.

- [ ] 서버(또는 DB 접근 정책)에서 로그인 사용자 확인
- [ ] 개인 데이터·도전장·게시글 소유자 검사
- [ ] 비로그인 사용자의 쓰기 기능 차단 안내

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
