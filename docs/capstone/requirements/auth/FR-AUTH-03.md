# FR-AUTH-03 로그아웃

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 안재우
- 작업 체크: [M01](../../milestones/M01.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **미구현**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-AUTH-04](FR-AUTH-04.md), [FR-REV-01](../rev/FR-REV-01.md)

## 시작 조건

사용자가 로그인한 상태다.

## 입력

로그아웃 버튼 선택.

## 처리 흐름

1. 인증 서비스의 로그아웃을 요청한다.
2. 성공하면 로그인 상태와 화면의 개인 데이터 캐시를 비운다.
3. 비회원 홈 또는 로그인 화면으로 이동한다.

## 출력과 저장

로그아웃 완료를 표시한다. 서버의 학습 기록·게시글은 삭제하지 않는다.

## 예외 처리

통신 실패로 로그아웃 여부를 확인할 수 없으면 실패와 재시도를 안내한다. 성공한 것으로 처리하지 않는다.

## 현재 상태와 남은 일

로그아웃 기능 없음.

- [ ] 로그아웃 버튼과 인증 서비스 로그아웃 연동
- [ ] 화면의 개인 데이터 상태 초기화

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
