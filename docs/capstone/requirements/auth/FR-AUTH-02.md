# FR-AUTH-02 로그인

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 안재우
- 작업 체크: [M01](../../milestones/M01.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **목업**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-AUTH-01](FR-AUTH-01.md), [FR-AUTH-04](FR-AUTH-04.md)

## 시작 조건

가입 및 필요한 이메일 확인을 완료한 계정이 존재한다.

## 입력

이메일과 비밀번호. 비밀번호는 화면에서 가리고 보안 연결로 전송한다.

## 처리 흐름

1. 입력을 검사한다.
2. 인증 서비스가 자격 정보를 검증한다.
3. 성공하면 로그인 상태를 발급한다.
4. 학습 홈 또는 로그인 전에 요청한 허용된 내부 화면으로 이동한다.

## 출력과 저장

로그인한 사용자 정보와 본인의 학습 기록을 표시한다. 사용자 식별자는 서버의 로그인 정보에서 얻는다.

## 예외 처리

틀린 정보는 일반적인 로그인 실패로 안내한다. 확인 대기 계정과 네트워크 오류를 안내하고 비밀번호를 로그에 남기지 않는다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 계정 A와 B로 각각 로그인하면 각자의 닉네임과 본인 기록이 표시된다. | 미충족 |
| A | 틀린 이메일·비밀번호는 로그인되지 않고 일반적인 실패 안내를 표시한다. | 미충족 |
| B | 로그인 전에 요청한 내부 화면으로 돌아가며, 외부 주소로의 복귀는 거부한다. | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

로그인 화면만 있고 실제 인증은 처리하지 않음.

- [ ] 인증 서비스 로그인 연동
- [ ] 로그인 사용자 정보로 화면 상단·대시보드 표시
- [ ] 로그인 후 복귀 주소 처리

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
