- 작업 체크: [M02](../../milestones/M02.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-QST-01](../qst/FR-QST-01.md), [FR-SYS-02](../sys/FR-SYS-02.md), [DR-02](../../common/data.md)

## 시작 조건

개념 자료에 relatedQuestionIds가 등록되어 있다.

## 입력

선택한 Q번호 또는 문제에 연결된 단원·개념 식별자.

## 처리 흐름

1. 관련 번호가 문제 데이터에 존재하는지 확인한다.
2. 존재하면 해당 문제 풀이를 연다.
3. 문제 화면에서는 그 번호를 참조하는 개념 목록을 표시한다.
4. 선택한 개념 본문으로 돌아간다.

## 출력과 저장

Q번호를 기준으로 양방향 이동을 제공한다. 원본의 문제 분류와 관련 개념 연결은 별도 관계로 관리한다.

## 예외 처리

없는 번호는 미등록으로 표시하고 다른 문제로 대신 연결하지 않는다. 삭제되거나 잘못된 번호의 직접 주소도 미등록으로 안내한다.

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
