# FR-LRN-04 학습 완료 표시

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 정재호
- 작업 체크: [M03](../../milestones/M03.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료·서버 미연결**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-AUTH-04](../auth/FR-AUTH-04.md), [FR-REV-03](../rev/FR-REV-03.md), [DR-03](../../common/data.md)

## 시작 조건

로그인 사용자가 유효한 개념 단원을 열었다.

## 입력

단원 ID와 완료 또는 취소 선택.

## 처리 흐름

1. 현재 상태를 확인한다.
2. 사용자·단원 조합의 완료 상태를 서버에 저장한다.
3. 목록과 대시보드의 완료 수를 갱신한다.

## 출력과 저장

완료 여부와 완료 시각을 저장한다. 완료 표시는 사용자의 읽음 표시이며 내용 숙달을 자동 판정하는 값이 아니다.

## 예외 처리

반복 요청은 동일 상태를 유지하며 중복 완료 행을 만들지 않는다. 저장 실패 시 기존 상태를 유지하고 재시도를 안내한다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 완료 표시·취소가 완료 수에 바로 반영되고, 로그아웃 후 다시 로그인해도 유지된다. | 부분 |
| B | 같은 단원을 여러 번 완료해도 1만 증가하고, 다른 기기에서도 같은 상태가 보인다. | 부분 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

완료 표시·취소와 대시보드 완료 수가 동작하지만 브라우저(localStorage)에만 저장됨.

- [ ] 사용자·단원 조합으로 서버 저장
- [ ] 로그인 시 서버 값으로 화면 초기화

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-04](../../tests/AT-04.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
