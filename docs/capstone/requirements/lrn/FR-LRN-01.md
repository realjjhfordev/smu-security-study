# FR-LRN-01 단원과 개념요약 조회

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 정재호
- 작업 체크: [M02](../../milestones/M02.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-SYS-02](../sys/FR-SYS-02.md), [DR-02](../../common/data.md)

## 시작 조건

개념 자료가 등록되어 있다. 공개 개념 열람은 로그인 없이 허용한다.

## 입력

PART, SECTION, 개념 식별자. SECTION은 1~42의 전역 번호로 구분한다.

## 처리 흐름

1. 7개 PART와 소속 단원을 표시한다.
2. 단원 선택 시 제목·목차·본문을 조회한다.
3. 목차를 누르면 해당 본문으로 이동한다.
4. 이전·다음 단원으로 이동한다.

## 출력과 저장

표·목록·코드·이미지를 포함한 본문을 읽을 수 있게 표시한다. 개념 분류와 출제포인트는 [DR-02](../../common/data.md)를 기준으로 제공한다.

## 예외 처리

미등록 자료는 준비 중으로 표시한다. 잘못된 단원 번호는 유효한 기본 단원으로 안내하고 화면 오류를 발생시키지 않는다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 7개 PART·42개 단원 본문을 모두 열 수 있고, 이전·다음 이동이 첫·마지막 단원에서 범위를 벗어나지 않는다. | 충족 |
| B | 본문 목차를 누르면 해당 위치로 이동하고, 잘못된 단원 번호 주소는 기본 단원으로 열린다. | 충족 |
| C | 단원 안에서 개념별로 골라 볼 수 있다(대표 개념 데이터 이후). | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

42개 단원 본문·본문 목차·이전/다음 이동·준비 중 표시가 동작함. 서버 연동이 필요 없는 기능.

- [ ] 개념 단위 선택은 대표 개념 데이터(DR-02)가 생긴 뒤 추가

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-03](../../tests/AT-03.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
