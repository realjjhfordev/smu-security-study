# FR-REV-02 개념별 첫 풀이 정답률과 취약 판정

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 곽다인
- 작업 체크: [M03](../../milestones/M03.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **미구현**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-REV-01](FR-REV-01.md), [BR-01](../../common/rules.md), [BR-02](../../common/rules.md), [DR-02](../../common/data.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

일반 기출과 대표 개념 연결 및 제출 기록이 존재한다.

## 입력

사용자, 대표 개념 ID, 일반 기출 최초 제출 기록.

## 처리 흐름

1. 개념별로 서로 다른 문제의 최초 유효 제출만 선택한다.
2. 맞힌 수를 푼 문제 수로 나눠 백분율을 계산한다.
3. 5문항 미만은 기록 부족, 5문항 이상·60% 미만은 취약으로 표시한다.

## 출력과 저장

개념명, 서로 다른 풀이 문제 수, 최초 정답 수, 정답률, 판정 상태를 표로 표시한다. 표시 반올림 전 값으로 판정한다.

## 예외 처리

0문항은 0% 대신 미학습으로 표시한다. 재풀이·AI·도전장 제출은 일반 기출 최초 정답률을 변경하지 않는다. 대표 개념이 없는 문제는 미분류로 별도 집계한다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 같은 개념 5문항 중 처음 2개를 맞히면 40%·취약이고, 이후 모두 다시 맞혀도 40%다. | 미충족 |
| A | 4문항만 풀면 기록 부족, 5문항 중 3개 정답이면 60%·취약 아님이다. | 미충족 |
| B | 0문항은 미학습, 대표 개념이 없는 문제는 미분류로 따로 집계한다. | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

전체 첫 풀이 정답률만 있고, 개념별 집계와 기록 부족·취약 판정이 없음.

- [ ] 대표 개념별 최초 제출 집계
- [ ] 미학습·기록 부족·취약 판정 표
- [ ] 시연 개념 문항에 대표 개념 지정(DR-02)

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험
