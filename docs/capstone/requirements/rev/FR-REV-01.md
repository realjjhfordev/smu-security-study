# FR-REV-01 개인 풀이 기록과 복습 목록

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 곽다인
- 작업 체크: [M03](../../milestones/M03.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료·서버 미연결**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-QST-03](../qst/FR-QST-03.md), [FR-QST-04](../qst/FR-QST-04.md), [BR-03](../../common/rules.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

사용자의 저장된 제출 기록이 존재하거나 아직 0건이다.

## 입력

로그인 사용자, 최근 기록 조회 또는 복습 대상 문제 선택.

## 처리 흐름

1. 본인의 일반 기출 기록을 조회한다.
2. 문제별 마지막 유효 제출을 구한다.
3. 오답이거나 확신도가 헷갈려요·모르겠어요이면 복습 목록에 넣는다.
4. 다시 풀기로 공통 화면을 연다.

## 출력과 저장

최근 기록은 최신순으로 문제 번호·정오답·확신도·시각을 표시한다. 같은 문제는 복습 목록에 한 번만 표시한다.

## 예외 처리

기록 0건은 학습 시작 안내를 표시한다. 조회 실패를 0건으로 오인시키지 않는다. 마지막 제출이 정답·확실해요이면 복습 대상에서 제외한다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 오답, 또는 정답이지만 헷갈려요·모르겠어요인 문제는 복습 목록에 있고, 정답·확실해요로 다시 풀면 빠진다. | 충족 |
| A | 계정 A와 B의 복습 목록이 섞이지 않는다. | 미충족 |
| B | 다른 기기에서 로그인해도 같은 목록이고, 조회 실패를 '복습할 문제 없음'으로 표시하지 않는다. | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

마지막 제출 기준 복습 목록(오답 또는 확실해요가 아닌 답)과 최근 제출 10건이 동작함(practiceStats).

- [ ] 서버의 본인 제출 기록으로 계산
- [ ] 조회 실패와 0건을 구분

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-08](../../tests/AT-08.md)

시험 결과는 연결된 시험 파일에 기록하고, 이 기능의 수용 기준 확인 내역·커밋·PR은 마일스톤의 작업 기록에 남긴다. 한 시험의 합격이 전체 세부 기준의 충족을 뜻하지 않는다.
