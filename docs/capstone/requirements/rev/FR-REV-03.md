# FR-REV-03 학습 대시보드

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 곽다인 및 정재호
- 작업 체크: [M03](../../milestones/M03.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료·서버 미연결**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-LRN-04](../lrn/FR-LRN-04.md), [FR-REV-01](FR-REV-01.md), [FR-REV-02](FR-REV-02.md)
- 집계·채점·공개 시점: [공통 업무 규칙](../../common/rules.md)의 관련 ID만 확인

## 시작 조건

사용자가 로그인해 학습 홈을 열었다.

## 입력

본인 완료 단원, 일반 기출 제출 기록, 복습 대상 목록.

## 처리 흐름

1. 완료 단원 수를 계산한다.
2. 일반 기출 누적 제출 수와 서로 다른 최초 풀이의 전체 정답률을 계산한다.
3. 복습 대상 수를 표시한다.
4. 개념·문제·복습으로 이동한다.

## 출력과 저장

분모·집계 범위를 표시한다. 일반 기출 누적 횟수에는 재풀이를 포함하되 AI·도전장은 포함하지 않는다.

## 예외 처리

불러오는 중·기록 없음·조회 실패를 구분한다. 개별 집계가 실패하면 임의의 0을 성공 값처럼 표시하지 않는다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 4개 지표가 로그인한 계정의 기록과 일치한다(같은 문제를 두 번 풀면 누적 2회, 서로 다른 문제 1개). | 부분 |
| B | 불러오는 중·기록 없음·조회 실패를 구분해 표시하고 분모를 함께 보여준다. | 부분 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

완료 단원·누적 풀이·첫 풀이 정답률·복습 수 4개 지표가 브라우저 기록 기준으로 동작함.

- [ ] 서버 기록 기준으로 계산
- [ ] AI·도전장 제출 제외
- [ ] 불러오는 중·기록 없음·조회 실패 구분

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.
