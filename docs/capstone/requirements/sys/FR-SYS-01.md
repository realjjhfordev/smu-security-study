# FR-SYS-01 화면 이동과 주소 상태 복원

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 정재호 및 전원
- 작업 체크: [M07](../../milestones/M07.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **화면 완료**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [FR-LRN-01](../lrn/FR-LRN-01.md), [FR-QST-02](../qst/FR-QST-02.md), [NFR-UX-01](../../common/quality.md)

## 시작 조건

PC 또는 모바일 브라우저에서 서비스에 접속한다.

## 입력

메뉴, 단원·문제 주소, 검색 조건, 브라우저 뒤로 가기·새로고침.

## 처리 흐름

1. 메뉴에서 각 기능 화면으로 이동한다.
2. 선택한 단원·문제 식별자를 주소에 반영한다.
3. 새로고침·뒤로 가기 시 해당 화면을 복원한다.
4. 보호 화면은 권한 확인 후 표시한다.

## 출력과 저장

메뉴 선택 상태, 유효한 본문, 로딩·빈 결과·오류 안내를 제공한다. 문제 검색 조건의 주소 보존 범위는 D07을 따른다.

## 예외 처리

잘못된 화면명은 기본 화면으로 안내한다. 미등록 문제는 미등록으로 표시한다. 미저장 입력이 있는 이동은 손실 여부를 안내한다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 문제 번호가 들어간 주소를 새로 열면 같은 문제가 열리고, 단원 이동 후 뒤로 가기로 이전 단원이 돌아온다. | 충족 |
| A | 휴대폰 화면에서 메뉴 이동, 보기 선택, 제출이 가능하다. | 확인 필요 |
| B | 잘못된 화면 이름은 기본 화면으로 안내한다. | 충족 |
| C | 저장하지 않은 입력이 있을 때 화면을 떠나면 경고한다. | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

화면·단원·문제·검색어·PART가 주소에 반영되고 새로고침·뒤로 가기로 복원됨(StudyApp.tsx).

- [ ] 로그인 후 보호 화면 권한 확인 연결
- [ ] 기능별 화면을 나눌 경우 주소 복원 유지

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험
