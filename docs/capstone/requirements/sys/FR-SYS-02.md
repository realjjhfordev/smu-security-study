# FR-SYS-02 학습 자료 등록과 연결 검증

- 우선순위: 필수 기능 · 세부 기준은 A/B/C 등급([등급 정의](../../common/scope.md))
- 담당: 정재호
- 작업 체크: [M02](../../milestones/M02.md)에서 관리
- 현재 상태(2026-11-16, main 433584c): **부분**
- 완료 판정: 아래 A 기준을 모두 충족하고 연결 시험의 A 단계가 합격하면 기능 완료로 체크한다. B·C는 판정 열만 갱신한다.

## 필요한 문서만 읽기

- 선행·관련 요구사항: [DR-02](../../common/data.md), [BR-01](../../common/rules.md), [NFR-DAT-01](../../common/quality.md)

## 시작 조건

담당자가 검토할 자료와 고유 ID를 준비했다. 별도 관리자 웹 화면은 만들지 않는다.

## 입력

개념요약, Q번호, 단원·대표 개념·출제포인트, 보기 4개, 정답, 기본 해설, 자료 버전.

## 처리 흐름

1. 데이터 파일 또는 관리용 등록 절차로 입력한다.
2. 중복 ID·빈 내용·보기 수·정답 범위·연결 대상 존재를 검사한다.
3. 검증된 자료를 배포·DB에 반영한다.
4. 내용 검수 상태를 따로 기록한다.

## 출력과 저장

등록 문제와 미등록 참조를 구분한다. Q번호를 변경하지 않는다. 정답·해설은 최종 서버 채점 구조에서 공개 데이터와 분리한다.

## 예외 처리

형식 오류 자료는 게시하지 않는다. 기존 정답 수정 시 버전을 구분하고 과거 제출 결과를 조용히 재작성하지 않는다. 사실 검수 미완료와 형식 검증 완료를 구분한다.

## 수용 기준

| 등급 | 기준 | 11/16 판정 |
| --- | --- | --- |
| A | 527문항의 고유 번호·보기 4개·정답 1~4·해설·개념 연결이 자동 검사를 통과한다. | 충족 |
| A | 정답·해설이 공개 문제 데이터와 분리되어 서버에만 저장된다. | 미충족 |
| B | 대표 개념이 없는 문항 목록을 출력한다. | 미충족 |
| C | 정답을 수정하면 버전을 구분하고 과거 제출 결과를 다시 쓰지 않는다(BR-08). | 미충족 |

판정은 2026-11-16 main 433584c의 코드를 읽고 내린 것이다. 시험 실행 기록은 연결 시험 파일에 남긴다.

## 현재 상태와 남은 일

npm run test:questions·test:content가 527문항의 고유 번호·보기 4개·정답 범위·개념 연결을 자동 검사함. 정답이 공개 데이터와 같은 파일에 있음.

- [ ] 정답·해설을 공개 문제 데이터와 분리해 서버(DB)에 등록
- [ ] 대표 개념 누락 목록 출력

## 구현 작업 순서

1. 관련 코드와 최신 브랜치를 확인하고 현재 동작을 재현한다. 이미 충족한 부분은 유지한다.
2. 입력 검증과 위 처리 흐름을 구현한다. 권한·채점·저장은 해당 서버 경계에서 처리한다.
3. 실패·빈 결과·재시도 경로를 구현하고 기존 기능 연결을 확인한다.
4. 위 수용 기준과 아래 연결 시험을 수행해 증거를 남긴다. 미실시 항목은 완료로 표시하지 않는다.

## 연결 시험

- [AT-19](../../tests/AT-19.md)
