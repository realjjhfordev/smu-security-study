## 현재 구현과 목표의 구분

2026년 11월 16일 main 433584c의 코드를 기준으로 판정했다. 별도 브랜치나 외부 서비스에만 있는 작업은 포함하지 않았다.

| 영역 | 현재 상태 | 목표까지 남은 일 |
| --- | --- | --- |
| 개념 자료 | 42개 단원 본문·목차·검색·문제 연결 동작 | 대표 개념·출제포인트 데이터(DR-02), 사실 검수 |
| 문제 자료 | 기출 변형 527문항(Q001~Q527), PART 1~6(SECTION 01~38)에 있음. PART 7(SECTION 39~42)은 없음. 형식 자동 검사 통과(2026-11-17) | 정답·해설을 공개 데이터와 분리해 서버로 이동 |
| 풀이 화면 | 보기·확신도 선택, 제출, 해설, 다시 풀기 동작 | 서버 채점 |
| 기록·복습 | 첫 풀이 정답률, 마지막 제출 기준 복습, 대시보드 4개 지표가 브라우저 기록으로 동작 | 계정별 서버 저장, 개념별 판정(REV-02) |
| 회원 | 가입·로그인 화면 목업 | 인증 연동, 로그아웃, 권한 검사 |
| AI | 고정 샘플 문구 | 실제 모델 호출·저장·한도 |
| 도전장 | 브라우저에만 저장되는 샘플 | 초대·참가·일괄 제출·결과 전체 |
| 게시판 | 브라우저에만 저장되는 글·댓글 | 공유 저장, 상세 화면, 수정·삭제, 작성자 권한 |
| 주소 상태 | 화면·단원·문제·검색어 주소 반영과 뒤로 가기 복원 동작 | 로그인 후 보호 화면 연결 |

"부분 구현"은 목표의 일부만 구현되었다는 뜻이고, "목업"은 실제 외부 처리 없이 화면 반응만 제공한다는 뜻이다. 등록된 자료의 수는 내용 정확성 검증 완료 수와 다르다.

## 핵심 이용 흐름

가입·로그인 → 단원과 개념 선택 → 기출문제와 확신도 제출 → 서버 채점·해설 → 복습·약점 확인 → AI 추가 해설 또는 보완문제 생성 → 재풀이. 도전장과 게시판은 동일 계정·공용 데이터 저장 기반을 사용한다.
