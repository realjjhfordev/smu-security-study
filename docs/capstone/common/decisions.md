# 미확정 정책과 근거

[문서 안내](../README.md)

> D01~D08은 아직 제안이다. AI는 확정된 정책으로 취급하지 않는다. 변경 시 아래 결정 이력을 작성하고 영향받는 기능·시험 파일도 갱신한다.

다음은 계획서에 수치나 세부 동작이 없는 부분을 구현 가능하도록 제안한 정책이다. 팀 검토 후 확정하고 문서 버전을 1.0으로 갱신한다. 필수 기능 자체를 보류한다는 뜻은 아니다.

S1 정보보안기사 학습플랫폼 계획서 역할분담 수정본, 총 5쪽. 1~3쪽은 필수 범위·시연 기준, 4쪽은 역할 분담, 5쪽은 연결 순서와 취약 기준의 근거다.

S2 GitHub realjjhfordev/smu-security-study, main 433584c. 2026년 11월 12일 조회. 주요 근거는 StudyApp.tsx, AuthMockup.tsx, QuestionPractice.tsx, question-bank.ts 및 콘텐츠 데이터다.

S3 배포 사이트 https://smu-security-study.vercel.app/ 의 2026년 11월 10일 기능 점검. 문제 제출·복습·저장 유지·개념 연결과 예시 기능 구분을 확인했다.
