## 외부 서비스 경계

브라우저는 화면과 사용자 입력을 처리한다. 서버는 사용자 확인, 권한 검사, 채점, AI 호출, 결과 저장을 처리한다. 인증 서비스는 계정과 로그인 상태를, 공용 DB는 지속 저장을 담당한다. 프런트엔드에 서버 비밀키를 포함하지 않는다.

| 연결 대상 | 요청과 결과 | 실패 처리 |
| --- | --- | --- |
| 인증 | 가입·로그인·로그아웃 요청과 인증 상태 | 계정 상태와 일반 실패를 구분하고 재시도 안내 |
| DB | 권한에 따른 조회·제출 저장·생성 상태 변경 | 실패를 성공으로 표시하지 않음. 중복 요청 안전 처리 |
| AI | 문제·선택 답 기반 설명 또는 보완문제 생성 | 형식 검증·시간 제한·호출 한도·수동 재시도 |
| 배포 | 공용 HTTPS 주소와 서버 환경 설정 | 필수 설정 누락 시 해당 기능을 명확히 비활성화 |
