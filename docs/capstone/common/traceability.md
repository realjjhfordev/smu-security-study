표의 기능 ID는 FR 접두어를 생략했다. 각 상세 요구사항의 입력·예외·수용 기준도 반드시 검증한다. 통합시험 하나의 성공으로 연결된 모든 세부 조건을 자동 완료 처리하지 않는다.

## 우선 구현 순서

1단계는 공용 DB·계정·서버 채점·계정별 저장이다. “로그인 → 기출 1문항 → 채점 → 다른 기기에서 기록 조회”를 먼저 연결한다. 2단계는 대표 개념 태깅과 복습·통계다. 3단계에서 AI, 도전장, 게시판을 공통 인증·저장·채점 기능에 연결한다. 마지막으로 AT-20을 공용 배포 주소에서 수행한다.

## 공동 작업의 연결 지점

윤도경과 곽다인은 제출 입력·저장 결과·최초 풀이 기준을 함께 확정한다. 정유민은 같은 문제 화면에서 AI 문제를 풀 수 있도록 문제 형식을 맞춘다. 이재윤은 서버 채점 함수를 재사용하되 도전장 공개 시점과 통계 제외 규칙을 적용한다. 안재우는 모든 담당자가 같은 사용자 식별자를 사용하도록 인증 정보를 제공한다.
