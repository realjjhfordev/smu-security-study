# 공통 업무 규칙

[문서 안내](../README.md)

| ID | 등급 | 규칙 |
| --- | --- | --- |
| BR-01 | A | 일반 기출의 첫 풀이란 동일 사용자·동일 원본 Q번호에 대한 최초 성공 저장 제출이다. 재시도 요청은 새 풀이가 아니다. 새로 시작한 재풀이는 별도 기록이다. |
| BR-02 | A | 개념별 정답률은 대표 개념별 서로 다른 일반 기출의 최초 정답 수 ÷ 최초 제출 문제 수 × 100이다. AI·도전장은 제외한다. 0개는 미학습, 1~4개는 기록 부족, 5개 이상이면서 60% 미만은 취약이다. |
| BR-03 | A | 복습 대상은 일반 기출의 마지막 유효 제출이 오답이거나 확신도가 헷갈려요·모르겠어요인 문제다. 마지막 제출이 정답·확실해요이면 제외한다. 최초 정답률과 복습 대상은 독립 계산한다. |
| BR-04 | A | 도전장은 생성자 1명과 참가자 1명, 고정된 기출 5문항으로 진행한다. 정답 1개당 20점이고 높은 점수가 승리, 동점은 무승부다. 양쪽 제출 전 정답·해설·상대 점수는 비공개다. |
| BR-05 | A | AI는 사용자가 버튼을 누를 때만 서버에서 호출한다. 저장된 결과 재조회는 재생성하지 않는다. 사용자·전체 서비스 한도 도달 시 추가 호출을 차단한다. |
| BR-06 | A | 개념의 관련 기출 연결은 Q번호 기준이다. 문제의 분류 단원과 연결 개념은 다를 수 있다. 정답률 집계에는 대표 개념 1개를 사용하고 관련 개념은 여러 개 연결할 수 있다. |
| BR-07 | A | 학습 데이터는 사용자별로 분리하고, 도전장 결과는 해당 참가자에게, 게시글·댓글은 허용된 독자에게 공유한다. 작성자와 서버 시각은 서버가 결정한다. |
| BR-08 | C | 정답·본문 변경은 자료 버전으로 구분한다. 제출 당시 결과를 보존하고 과거 정답률을 자동 재작성하지 않는다. 재채점이 필요하면 별도 변경 승인과 검증을 수행한다. |

BR-08(자료 버전 관리)은 C 등급이다. 시연 기간에 정답을 고치면 해당 문항의 기존 제출을 시험용 데이터로 보고 지워도 된다.

BR-01~05의 핵심은 기존 계획서에 근거한다. 마지막 제출 기준 복습은 현재 구현을 이어받았다. 대표 개념 1개, 도전장 정답 공개 시점, 버전 관리 등 세부 동작은 이 문서의 제안 정책이며 [미확정 정책 문서](decisions.md)에서 확정한다.
