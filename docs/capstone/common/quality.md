# 비기능 요구사항

[문서 안내](../README.md)

등급은 [우선순위 등급](scope.md)을 따른다. 두 등급이 함께 적힌 항목은 다음처럼 나눈다.

- NFR-SEC-01: 개인 데이터·작성자 권한의 서버 검사와 비밀값 보호는 모두 A.
- NFR-DAT-01: 버튼 연타·저장 실패 시 성공 미표시는 A, 응답 유실 재전송 시험은 C.
- NFR-OPS-01: 계정별 하루 한도는 B, 서비스 전체 한도와 한도 조회 실패 차단은 C.
- NFR-COMP-01: PC Chrome과 휴대폰 1종(팀원 실제 기기)은 A, 나머지 브라우저는 C.

아래 수치는 별도 합의가 없는 항목에 대한 목표 제안이다. 측정 환경과 기준을 팀이 확정한 뒤 검증 결과를 기록한다. 운영 중 이미 달성한 성능을 의미하지 않는다.

## 최종 시연 조건

공용 배포 주소에서 서로 다른 두 계정과 두 브라우저 또는 기기를 사용한다. 시연용 기출 5문항은 동일 대표 개념으로 태깅하고 기본 해설을 확인한다. AI 추가 해설과 보완문제는 각각 실제 호출에 한 번 이상 성공해야 한다. 화면 예시와 브라우저 임시 저장만으로 해당 요구사항을 완료 처리하지 않는다.

## 변경 통제

팀원은 담당 기능 변경을 자신의 브랜치에서 개발하고 검사 후 PR로 main에 반영한다. 특정 팀장 승인을 필수로 두지 않는다. 대신 관련 담당자와 데이터 필드·채점·권한 정책의 변경을 공유하고, 연결 요구사항과 검증표를 함께 갱신한다. 공통 파일을 동시에 수정할 경우 작업 범위를 먼저 나눈다.
