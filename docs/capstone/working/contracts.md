# 기능 간 연결 규격 기록

M00에서 관련 담당자가 합의하고 실제 구현에 맞춰 채운다. 아래 항목은 확정된 API나 테이블 설계가 아니다.
필요할 때 관련 항목만 읽고, 내용이 커지면 기능별 파일로 분리해 링크한다.

| 연결 | 함께 확인할 내용 | 담당 | 확정 상태 |
| --- | --- | --- | --- |
| 인증 → 모든 개인 기능 | 서버에서 확인한 사용자 ID·세션·만료·거부 응답 | 안재우 및 전원 | 미확정 |
| 문제 → 채점 → 기록 | Q번호·버전·답·확신도·요청 ID·풀이 종류·저장 결과 | 윤도경·곽다인 | 미확정 |
| 자료 → 집계 | 대표 개념·관련 개념·출제포인트·기출 첫 풀이 기준 | 정재호·곽다인·윤도경 | 미확정 |
| AI → 공통 문제 화면 | 개인 AI 문제 ID·정답 비공개·재풀이·통계 제외 | 정유민·윤도경·곽다인 | 미확정 |
| 도전장 → 채점 | 고정 문제·버전·순서·일괄 제출·공개 시점 | 이재윤·윤도경 | 미확정 |
| 게시판 → 인증 | 작성자 확인·수정 삭제 권한・조회 공개 범위 | 안재우 | 미확정 |

## 확정 기록 양식

- 연결 이름:
- 실제 관련 코드 경로:
- 요청 필드와 자료형:
- 성공 결과와 실패 결과:
- 권한·중복 처리·저장 시점:
- 영향받는 요구사항·시험 ID:
- 결정자·일자·커밋 또는 PR:

비밀값과 실제 사용자의 개인정보는 예시에 넣지 않는다.
